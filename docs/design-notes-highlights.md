# 設計：畫線、筆記、我的重點、觀點

狀態：草案，待審。作者：雲端 agent。2026-11-20。

## 使用者是誰、怎麼用

Miranda，一個人，在手機和電腦上讀長影片的逐字稿（中文為主的閱讀模式）。

## 觀察到的事實

來自她帳號裡 Pieter Levels（3 小時 44 分，38 章）那支的紀錄：

- 104 條畫線，98 條是第一個分類「洞見」，6 條「疑問」，「要去做」0 條。
- 10 條是句子的一部分，其餘是整句。很多是連續好幾句（例如 t1116-0、-1、-2、t1125-0、t1129-0…）。
- 筆記 0 則。章節下的「換到你身上」回答 1 則。主張 1 個，觀點卡 0 張。
- 只讀到大約第 10 章（54 分鐘處）。

來自訪談（她的原話整理）：

- 筆記：「想寫的是整段或整章」「劃線的時候沒地方寫筆記，或是不一定要跟著某段」「寫了也存不起來」。
  實測：點句子開面板寫的筆記有存，但面板關掉後只剩一個 ✎ 記號，內容看不到。選字畫線的那條路完全沒有寫筆記的地方。
- 畫線：「沒有一個純劃線的標記」「一般只要劃線，疑問、洞見、要去做偶爾用」。
- 用途：之後只回來看畫線；拿來寫自己的東西。讀完最想帶走「一頁我自己的重點整理」。
- 筆記顯示：只要集中在一頁，逐字稿裡不要顯示。
- 淬煉和觀點卡：不是不需要，是很難用。「看不懂要做什麼」「畫線太多找不到」「規則太硬」「有 bug」（沒說是哪個）。

## 現在的資料（每支影片一份，存在 `reader_state.state`，跨裝置同步，整份覆蓋、時間新的贏）

```
hl:     { 句子id: "y" | "p" | "g" }          洞見／疑問／要去做
rng:    { 句子id: { zh:[起,迄], en:[起,迄] } }  只畫句子的一部分
notes:  { 句子id: 文字 }
refl:   { 章節id("c3"): 文字 }                 「換到你身上」的回答
claims: [ { id, text, ev:[句子id 或 "ai-c3"] } ]
cards:  [ { id, text, ev:[...], ... } ]        最多 3 張
```

句子 id 是 `t{秒數}-{句序}`，重跑影片後大致不變。章節 id 是 `c{序號}`，**重跑後章節數會變，序號就對不上**。

## 提案

### 1. 畫線：預設不分類

- 選字後底部那一列改成：`畫線`｜`畫線＋筆記`｜`⋯`｜`取消`。點 `畫線` 一下就完成。
- `⋯` 展開分類：洞見、疑問、要去做。分類是選填的標記。
- 既有的 `"y"` 重新解釋成「一般畫線」（她的 98 條黃色是因為洞見排第一個才選的）。新增 `"i"` 代表洞見。`"p"`、`"g"` 不變。

### 2. 筆記：可以不掛在句子上

新增 `memos: [ { id, at, text, t?, ids? } ]`
- `ids`：這則筆記對應哪幾句（選字後按「畫線＋筆記」時填入）。
- `t`：對應影片的哪個時間點（對某一章寫時 = 章節開始秒數）。兩個都沒有 = 對整支影片的筆記。
- 舊的 `notes[句子id]` 繼續讀，顯示時當成只有一個 id 的 memo。新寫的一律進 `memos`。

入口：
- 選字後的 `畫線＋筆記`。
- 點已畫線的句子開的面板（原本就有）。
- 每一章標題旁的「寫筆記」。
- 閱讀頁右下角固定一顆「＋筆記」，寫的是對目前讀到那一章的筆記。
- 「我的重點」頁最上面可以寫對整支影片的筆記。

逐字稿裡不顯示筆記內容，只保留 ✎ 記號。

### 3. 新分頁「重點」

分頁從「總覽／閱讀／淬煉／觀點卡」改成「總覽／閱讀／重點／觀點」。

「重點」頁：
- 依章節分組，章節標題可點回逐字稿。
- 每組列出畫線（連續的句子合併成一塊，只畫一部分的顯示那一部分）和筆記，照時間排。
- 上方篩選：全部｜有筆記｜洞見｜疑問｜要去做。
- 「複製全部」：整頁轉成 Markdown 放進剪貼簿。
- 「換到你身上」的回答也列在所屬章節下。

### 4. 修正：章節序號對不上

`refl` 的鍵和主張證據裡的 `ai-c3` 都用章節序號。改成用章節開始的秒數（`r{秒數}`、`ai-{秒數}`）。
載入時用目前的章節把舊鍵轉成新鍵；之後章節重切，就把它歸到「包含那個秒數」的章節。
她現有那則回答寫在舊的 c4，重跑前後章節不同，轉換時只能猜，會歸到現在的 c4。

### 5. 觀點（第二批）：取代淬煉和觀點卡

- 「重點」頁有「選取」模式：勾幾條畫線或筆記 → 「寫成觀點」。
- 編輯畫面：上面是勾選的引文，下面一個文字框寫自己的話。存檔就是一張觀點。
- 不再要求剛好 2 個證據，不限 3 張。0 條引文也可以存。
- 「觀點」分頁列出所有觀點，可編輯、刪除、複製。
- 既有的 `claims` 轉成觀點草稿，既有的 `cards` 照樣顯示。
- 拿掉火花、主張、鑄卡這些詞，拿掉四步驟進度列。AI 挑的火花不再混在畫線裡。

## 不做的

- 逐字稿內嵌顯示筆記。
- 匯出到 Notion／Obsidian（先用複製 Markdown）。
- 拖曳排序。

## 我不確定的地方

- `"y"` 重新解釋成一般畫線，會不會有她真的想標成洞見的被降級？
- `memos` 和舊的 `notes` 兩套並存，還是一次轉成 `memos`？同步是整份覆蓋，舊版頁面還開著的裝置會把新欄位蓋掉嗎？
- 手機上右下角的「＋筆記」會不會跟底部分頁列、選字列打架？
- 「重點」頁一百多條畫線的長度。合併連續句子後夠不夠？
- 她說的淬煉 bug 是哪一個，我沒有重現。
